# TierMaker-Program
티어메이커 웹사이트 제작

설치 없이 브라우저에서 바로 쓰는 티어표 만들기 도구예요.

## 사용법
1. **이미지 추가** 버튼을 누르거나, 이미지 파일을 창에 끌어다 놓거나, `Ctrl+V`로 붙여넣으면 아래 **대기 칸**에 이미지가 올라와요.
2. 이미지를 마우스로 끌어서 원하는 티어 줄에 놓으세요. 줄 안에서 순서도 바꿀 수 있어요.
   티어는 **S급 빌런 / A급 빌런 / B급 빌런 / C급 빌런 / 빌런 기각** 5개로 고정돼 있어요.
3. 티어 이름 칸이나 오른쪽 ⚙를 누르면 그 줄의 **색상**을 바꾸거나, 줄에 있는 이미지를 대기 칸으로 되돌릴 수 있어요.
4. **PNG로 저장**을 누르면 완성된 티어표가 이미지 파일로 저장돼요.
5. 이미지를 지우려면 끌어서 오른쪽 아래 **🗑 휴지통**에 놓으세요.

작업 내용은 그 브라우저에 자동으로 저장돼요. 다른 PC에서 이어서 하려면 `⋯` 메뉴의 **파일로 내보내기**를 누르고, 다른 PC에서 **파일 불러오기**로 여세요.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면의 뼈대 |
| `style.css` | 디자인 (색상, 크기, 간격) |
| `app.js` | 동작 (드래그, 색상 변경, 저장, PNG 만들기) |

## 내 PC에서 실행해 보기
이 폴더에서 아래 명령을 실행한 뒤 브라우저에서 http://localhost:5173 을 여세요.

```bash
python -m http.server 5173
```

## 배포 (GitHub Pages)
GitHub 저장소의 **Settings → Pages**에서 *Source*를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 설정하면
`https://makyung-maker.github.io/TierMaker-Program/` 주소로 누구나 접속할 수 있어요.
